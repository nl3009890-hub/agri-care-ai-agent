## 1. Thành phần trong gói ZIP
- `index.html`: Toàn bộ giao diện web và bộ suy luận của **Agri-Care AI Agent v2.4** (chạy trực tiếp trên trình duyệt, không cần cài đặt Python hay server).

## 2. Cách mở sử dụng ngay (Cho bạn và bạn bè)
1. Giải nén file `.zip` này.
2. Nhấp đúp chuột vào file **`index.html`** để mở bằng trình duyệt (Chrome, Edge, Safari...).
3. Nhấn nút **"Chạy Demo Tự Động (Auto-Walkthrough)"** trên góc phải để xem toàn bộ quy trình suy luận của AI Agent qua 3 kịch bản thời tiết/dịch bệnh.
